# Home Credit Default Risk Prediction

This repository contains my project developed as part of the GCI course competition based on the Kaggle Home Credit Default Risk dataset.

The project focused on predicting whether loan applicants will default or not using machine learning and statistical modeling techniques to assess borrower creditworthiness and default risk.

---

## Project Overview

The objective of this project was to build predictive credit risk models capable of identifying high-risk borrowers using customer demographic, financial, and behavioral data provided in the Home Credit dataset.

The workflow included:
- Data preprocessing and cleaning
- Missing value treatment
- Feature engineering
- Exploratory data analysis
- Model training and evaluation
- Performance comparison across multiple algorithms

---

## Models Used

The following models were implemented and compared:

- Logistic Regression
- XGBoost
- LightGBM
- CatBoost

The models were evaluated using classification performance metrics such as ROC-AUC and predictive stability to determine their effectiveness in credit default prediction.
